# 沪深300全收益 vs 二级债基指数

**在线看板：https://dul30984-cpu.github.io/hs300-vs-2ndbond/**

- 两条指数叠加：沪深300全收益（H00300）与二级债基指数，2004-12-31 = 1000。
- 滚轮缩放、拖动平移、悬停十字光标读数；红圈标出“300 全收益跌破二级债基”的时点。
- 口径切换：标定 Wind 885007 / 原始重建。

## 数据更新

每天北京时间 21:30 与 23:30，GitHub Actions（`.github/workflows/update.yml`）会自动：

1. 抓取中证指数官网的最新 H00300 收盘；
2. 拉取天天基金公开的基金净值，重建二级债基指数（等权、分红再投资、按 Wind 885007 于 2026-10-16 的 5163.65 标定）；
3. 若有新数据，提交 `data.json`，GitHub Pages 随即自动重新发布（约 1 分钟）。

也可以在 Actions 页面手动触发（workflow_dispatch）。

数据来源：中证指数官网、天天基金公开净值。二级债基指数为公开数据重建，非 Wind 官方序列。
